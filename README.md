# 🐕 Dog Adoption Power BI Dashboard

## Overview
This interactive Power BI dashboard provides data-driven insights into dog adoption trends, demographics, and outcomes. The goal is to analyze key metrics that help animal shelters optimize adoption rates and understand pet characteristics better.

---

## 📊 Key Features & Analysis
- **Adoption Dynamics:** Tracks adoption trends over time and evaluates success rates across different dog breeds.
- **Demographic Breakdown:** Analyzes dogs by age group, gender, size, and health status.
- **Data Modeling & DAX:** Includes custom DAX measures for dynamic KPIs, adoption speed calculations, and interactive filtering.
- **Interactive Visualizations:** Clean and modern UI design built with custom color palettes and structured user experience.
